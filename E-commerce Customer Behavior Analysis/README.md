# Датасет
https://archive.ics.uci.edu/dataset/352/online+retail?utm_source=chatgpt.com
Это реальные транзакционные данные британского интернет-магазина за 2010-2011 годы.

В датасете нет информации о себестоимости, скидках и категориях товаров, поэтому нужно анализировать не прибыль, а выручку

- Количество записей: 541909
- Количество признаков: 8

## Признаки
1) invoiceNo - номер заказа
2) StockCode - код товара
3) Description - название товара
4) Quantity - количество единиц
5) InvoiceDate - Дата и время покупки
6) UnitPrice - Цена за единицу
7) CustomerID - идентификатор покупателя
8) Country - страна
